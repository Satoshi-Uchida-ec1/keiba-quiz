# 収益モデルと広告要件

## 方針：広告あり無料。ただし段階導入

MVPは広告なしでリリースする。審査に通るだけのコンテンツ量とトラフィックがない段階で
広告を入れても収益はほぼゼロなのに、UXだけが悪化するため。

| フェーズ | 収益施策 |
| --- | --- |
| MVP | 広告なし。UXと問題品質に集中 |
| フェーズ2 | 解説記事を蓄積し、月1万PV規模でAdSense申請。配置は厳格に制限 |
| フェーズ3 | 広告非表示の少額サブスク、または投げ銭。書籍・乗馬体験等のアフィリエイト |

## 広告収益の現実的な期待値

個人運営のクイズサイトのRPM（1000PVあたり収益）は数百円規模。
月1万PVで数百〜千円台、月10万PVでようやく数万円。

さらにSPA構成では「1セッションで100問解いても1PV」になりやすく、PV課金と相性が悪い。

つまり**広告は主目的にならない**。UXを削ってまで最適化する対象ではない、という前提で設計する。

## AdSense審査への対応

AdSenseはアカウント審査とサイト審査の両方があり、通常数日、場合により2〜4週間かかる。
最も多い不承認理由が「コンテンツの不足・品質不足」。

クイズアプリは構造的にここが弱い。動的描画されるSPAは、審査側から見ると
「テキストがほとんどない1ページ」に映る。

**対策**：解説記事（M-12）を10〜20本、静的ページとして持つ。
これは審査対策、SEO流入、クイズの解説コンテンツの三役を兼ねる。
`tech.md` の「SPA単体にしないこと」はこの要件に対応している。

## 競馬というテーマの広告ポリシー上の扱い

Googleはギャンブル関連コンテンツについて認定申請や「責任あるギャンブル」情報の掲載などの
条件を課しているが、これは主に広告主側のポリシー。

サイト運営者側については、日本の公営ギャンブル（競馬・競輪・競艇・オートレース）を扱う
サイトであればポリシー違反にはならないとされ、制限対象とされているのはオンラインカジノ等。
またギャンブル系広告を自サイトに配信させる場合、管理画面の「広告の許可とブロック」で
該当カテゴリを許可に設定する必要がある。

本アプリは知識クイズであり馬券購入を促すものではないため、リスクは低い。
ただし**馬券の予想・買い方指南に踏み込むほど審査とポリシーの難易度が上がる**ため、
そこには踏み込まない（スコープ外）。

## 広告配置の制約（厳守事項）

AdSenseは誤クリックを誘発する配置を明確に禁止している。
クイズアプリは選択肢ボタンが並ぶ性質上、ここが最大のリスク。

無効トラフィックや誤クリック誘発によるアカウント停止は復帰が極めて困難で、
「貼ってみて怒られたら直す」が通用しない。

### 配置を許可する場所

- 解説記事ページ（P-10）の本文中および末尾
- セッション結果画面（P-06）の下部。「もう1セット」ボタンから十分離した位置
- サイトフッター

### 配置を禁止する場所

- 出題画面（P-04 / P-05）のすべて
- 選択肢ボタン、「次の問題へ」ボタンから1画面スクロール以内の領域
- 回答直後の全画面広告（インタースティシャル）
- ページ遷移時のオーバーレイ

## プライバシー・同意管理

- プライバシーポリシーページ（P-13）を必須とする
- Cookieや広告タグで外部に情報を送信する場合、電気通信事業法の外部送信規律により
  通知・公表義務がある。送信先の一覧を掲載する
- パーソナライズド広告を配信する場合は同意取得の仕組みを検討する

## 代替収益手段

広告より文脈に馴染む可能性がある選択肢。

- 競馬関連書籍・映像作品のアフィリエイト（解説記事の末尾に「もっと知りたい人へ」として設置）
- 乗馬体験・競馬場ツアーのアフィリエイト
- 投げ銭（Buy Me a Coffee 等）

いずれも「広告」というより「関連情報」として提示できるため、ユーザーの拒否感が相対的に小さい。
