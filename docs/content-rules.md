# コンテンツ設計と権利ルール

問題データを扱うときは必ずこのファイルを読むこと。
特に「権利・法務ルール」は本プロジェクト最大のリスク領域。

## ジャンル（7分類）

| # | ジャンル | 扱う範囲 | 初心者向き |
| --- | --- | --- | --- |
| 1 | 馬の生物学 | 生態、体の構造、毛色、品種、寿命、行動 | ◎ 競馬を知らなくても解ける |
| 2 | 競馬の基礎・ルール | レース種別、グレード制、馬券の種類、競馬場、用語 | ◎ 入門の本命 |
| 3 | 騎手・調教師・厩舎 | 主要人物、記録、勝負服、免許制度 | ○ |
| 4 | 血統 | サイアーライン、母系、ニックス、著名種牡馬 | △ コア向け |
| 5 | 名馬・歴史 | クラシック、三冠、G1、記録、伝説的名馬 | ○ |
| 6 | 海外・地方・ばんえい | 海外G1、地方競馬、ばんえい競馬 | △ |
| 7 | 馬文化 | 馬術・乗馬、競馬場グルメと観戦文化、文学・映画の中の馬 | ◎ 非競馬層の入口 |

ジャンル7に外部IP（ウマ娘等）は含めない。観戦文化・馬術・文芸で構成する。

## 難易度の統一基準

ジャンル間で体感を揃えるため、「正答に必要な前提知識の階層」を共通の物差しにする。

| 難易度 | 基準 | 想定正答率 |
| --- | --- | --- |
| easy | 競馬を知らない人でも常識や推測で解ける／ファンなら誰でも知っている | 70〜85% |
| normal | 競馬を数年見ているファンなら答えられる。前提知識が1つ要る | 45〜65% |
| hard | 記録・血統の詳細など、意識して調べないと知らない | 20〜40% |

想定正答率は作成時の目安。運用開始後、実測値と乖離した問題はタグを見直す。

## サンプル問題

形式の参考用。いずれも自前執筆の例。

> **注意：以下のサンプルは事実の一次情報確認が済んでいない。** 問題データへ流用する場合は、
> 必ず人間が一次情報で確認し、`source` を記入してから使うこと。各サンプルの「要確認」も参照。

**ジャンル2・easy**
- Q：日本ダービー（東京優駿）の距離は？
- 選択肢：芝1600m / 芝2000m / **芝2400m** / 芝3200m
- 解説：3歳牡牝が東京競馬場の芝2400mで争う、世代の頂点を決めるレース。
- 要確認：事実の一次情報確認

**ジャンル2・normal**
- Q：日本の中央競馬でグレード制が導入されたのは何年？
- 選択肢：1974年 / **1984年** / 1994年 / 2004年
- 解説：1984年にG1・G2・G3の格付けが導入された。それ以前は八大競走という区分が使われていた。
- 要確認：「八大競走という区分」は、格付け制度と伝統的な呼び名を同列に扱っており誤解を招く。表現を見直す

**ジャンル5・normal**
- Q：無敗でクラシック牡馬三冠を最初に達成した馬は？
- 選択肢：シンザン / **シンボリルドルフ** / ディープインパクト / コントレイル
- 解説：1984年の達成。無敗三冠は他にディープインパクト（2005年）、コントレイル（2020年）。
- 要確認：事実の一次情報確認

**ジャンル4・hard**
- Q：2020年に無敗三冠を達成したコントレイルの父は？
- 選択肢：**ディープインパクト** / キングカメハメハ / ハーツクライ / ステイゴールド
- 解説：父子ともに無敗三冠を達成したのは史上初。
- 要確認：問題文の「無敗三冠」がヒントになっており、hard の想定正答率（20〜40%）に合わない可能性が高い。難易度か問題文を見直す

**ジャンル1・easy**
- Q：サラブレッドの妊娠期間に最も近いのは？
- 選択肢：約6か月 / 約8か月 / **約11か月** / 約15か月
- 解説：約330日前後。1月1日生まれの馬が有利とされるのは、種付け時期がこの期間から逆算されるため。
- 要確認：解説後半の因果関係が成り立っていない（馬齢の数え方と種付け時期の話が混ざっている）。一次情報を確認して書き直す

**ジャンル6・normal**
- Q：現在ばんえい競馬を開催している唯一の競馬場がある都市は？
- 選択肢：旭川市 / **帯広市** / 岩見沢市 / 北見市
- 解説：売上減少により旭川・北見・岩見沢の3市が2006年度限りで撤退し、2007年度から帯広市の単独開催となった。
- 要確認：問題文が「現在」で、下記「時事問題の陳腐化対策」の2（時点を明記）に反する。「〇年時点で」に直し、`isTimeSensitive` と `asOf` を設定する

## 時事問題の陳腐化対策

「現役リーディング」「最新のG1勝ち馬」のように事実が変わる問題は以下で扱う。

1. `isTimeSensitive` と `asOf`（基準日）をデータに設定する
2. 問題文に必ず時点を明記する（例：「2025年時点で〜」）
3. 主軸は三冠馬や歴代記録など、確定した事実に置く
4. 年1回、時事フラグの立った問題をまとめてレビューする

# 権利・法務ルール

## 大原則：事実は自由、表現は保護される

レース結果、距離、記録、血統といった**事実そのものは著作権の保護対象ではない**。
一方、それを書き表した文章、写真、データベースの構造や選択・配列は保護される。

したがって運用は一本槍に統一する。

> **一次情報で事実を確認する → 問題文・選択肢・解説はすべて自前で書き起こす。**

参照はしてよい。転載してはならない。

## AIの下書きと人間の確認

言語モデルは競走馬の記録・血統・レース結果を、高い確率で、しかも自信を持って誤る。
そのため、AIには下書きまでを任せ、公開の可否は人間の確認で決める。

| 担当 | やること |
| --- | --- |
| AI | 問題文・選択肢・正解・解説の下書き。`status: "draft"`、`source` は空欄。自信のない箇所を `reviewNote` に書く |
| 人間 | 一次情報で確認し、`source` に確認元を書く。誤りを直し、`reviewNote` を消して status を進める |

AIは `source` を書かない。存在しない出典を作ってしまう恐れがあるため。

人間が確認するのは正解だけではない。

- 問題文の前提
- **誤答の選択肢が本当に誤りであること**（別解になっていないか）
- 解説に含まれるすべての年号・人名・数字
- 難易度が下記の基準に合っているか

AIが比較的正確に書けるのは、ルール・用語・馬の生物学・広く知られた名馬の話。
細かい記録（勝利数・タイム・着順）、血統の細部、地方・海外の話は誤りやすいので、下書きを頼む範囲も慎重に選ぶ。

このルールは解説記事（M-12）の本文にも同じく適用する。

## 主要データソースの利用条件

| ソース | 事実確認での参照 | 転載・データ利用 | 備考 |
| --- | --- | --- | --- |
| JRA公式 | 可 | 不可 | 私的利用・引用の範囲を超える二次利用は事前申請・許諾が必要で、申請は法人に限られる |
| netkeiba | 可 | 不可 | 規約で私的利用の範囲を超える複製・販売・出版を禁止。広告掲載サイトは私的利用の範囲外と明示。レース映像・調教タイム・厩舎コメント等は一切二次利用不可 |
| JBIS-Search | 可 | 不可 | 二次利用規約で営利目的の利用・加工改変・第三者が自由に取得できる場所への掲載を禁止 |
| 書籍・雑誌 | 可 | 不可 | 問題文の丸写しは当然不可 |

**一般公開するサイトは「私的利用」に当たらない。** 無料公開だから大丈夫、という理解は誤り。投げ銭を受け付けるならなおさら。

スクレイピングのコードは書かない。netkeiba は支障があれば予告なく通信制限をかけると明示している。

## 画像の使用ルール

競走馬・騎手・レースの写真は事実上すべて他人の著作物。検索で出てくる画像はすべて使用不可と考える。

| 種別 | 可否 | 条件 |
| --- | --- | --- |
| 報道・公式サイトの写真 | 不可 | 撮影者・媒体に著作権がある |
| 自分で競馬場で撮影した写真 | 要確認 | 施設の入場規約で商業利用が制限される場合がある。投げ銭を受け付けるサイトは商業利用とみなされうる |
| フリー素材の一般的な馬の写真 | 可 | ライセンスを個別確認（商用可か、改変可か、クレジット要否、モデルリリースの有無） |
| AI生成画像 | 条件付き | 実在馬の再現は避ける。装飾的イラストに限定し、方針を統一する |
| 自作イラスト・アイコン | 可 | |

**MVPの方針**：写真は使わない。自作またはライセンスが明確なアイコン・イラストのみ。
写真が本当に機能するのはジャンル1（毛色・品種の識別）なので、そこだけフリー素材で限定的に導入する。
名馬や騎手の写真は諦める。テキストだけで十分成立する。

## 音の使用ルール

| 種別 | 可否 | 備考 |
| --- | --- | --- |
| JRAのファンファーレ | 不可 | 著作物。競馬アプリで最も使いたくなるが使えない |
| レース実況音声・中継音声 | 不可 | 放送局・JRAの著作物 |
| 市販楽曲 | 不可 | JASRAC管理楽曲をWebで使う場合は個別の許諾と使用料が必要 |
| ロイヤリティフリー音源 | 可 | DOVA-SYNDROME、魔王魂、効果音ラボ等。多くはクレジット表記が条件 |

**MVPの方針**：音なし。フェーズ3で正解・不正解の短い効果音のみ、ライセンス明確な素材で、
デフォルトOFFで導入する。自動再生は行わない。

クレジット表記が必要な素材を使う場合、`docs/credits.md` に記録し、P-12（このサイトについて）に表示する。

## 問題制作フロー

1. ネタ出し（問題リクエスト、解説記事の執筆過程、自分の関心から）
2. 問題文・選択肢・解説を執筆（人間が書くか、AIが下書きする）。この時点では `status: "draft"`
3. 一次情報で事実確認。`source` に確認元をメモ（人間のみ）
4. 誤答選択肢の妥当性チェック（明らかに不自然な選択肢や、別解になりうる選択肢を混ぜない）
5. 時事性の判定。該当すれば `isTimeSensitive` と `asOf` を設定
6. `reviewNote` の指摘をすべて解消したら項目ごと消し、`status` を published に
7. `npm run questions` でエラーが出ないことを確認
