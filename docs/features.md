# 機能要件

要件IDで参照する。実装完了時はどのIDを満たしたか明示すること。

## MUST（MVPに必須）

| ID | 機能 | 内容 |
| --- | --- | --- |
| M-01 | ジャンル選択 | 7ジャンルから選択。「全ジャンルミックス」も選べる |
| M-02 | 難易度選択 | 簡単／普通／難しい。「おまかせ」も選べる |
| M-03 | 4択出題 | 1画面1問。選択肢の並びは毎回シャッフル |
| M-04 | 即時フィードバック | 回答直後に正誤を表示。正解の選択肢をハイライト |
| M-05 | 解説表示 | 要点1〜2文を常時表示。「もっと詳しく」で折りたたみ展開 |
| M-06 | セッション結果 | 1セット10問終了時に正答数・所要時間・間違えた問題の一覧 |
| M-07 | 復習機能 | 間違えた問題を記録し、次セッションで優先再出題（Leitner方式の軽量版） |
| M-08 | 重複回避 | 同一セッション内で同じ問題を出さない。直近N問の再出題を抑制 |
| M-09 | 成績の可視化 | ジャンル別・難易度別の正答率をグラフ表示 |
| M-10 | 進捗のローカル保存 | ログイン不要。IndexedDB / localStorage に保存 |
| M-11 | 誤答通報 | 各問題から1タップで通報。通報理由を選択できる |
| M-12 | 解説記事ページ | 10〜20本の読み物。静的ページとしてクロール可能な形で配信 |
| M-13 | プライバシーポリシー | 外部送信規律に対応した記載を含む |
| M-14 | レスポンシブ対応 | スマホブラウザで親指操作が完結する |

M-12 は単なる付加機能ではない。AdSense審査、SEO流入、クイズの解説コンテンツの三役を兼ねる。
理由は `ads.md` を参照。

## SHOULD（フェーズ2）

| ID | 機能 | 内容 |
| --- | --- | --- |
| S-01 | デイリーチャレンジ | 全ユーザー共通の1日5問。リアルタイム対戦の代替 |
| S-02 | 結果シェア | SNS向けのテキスト／画像を自動生成。ネタバレなしの形式 |
| S-03 | アカウント制 | 端末間で進捗を同期。任意であって必須にしない |
| S-04 | バッジ・実績 | ジャンル制覇、連続正解などの達成記録 |
| S-05 | ストリーク | 連続日数。「フリーズ」相当の逃げ道を必ず併設 |
| S-06 | 問題リクエスト | 「こういう問題が欲しい」をユーザーから収集 |
| S-07 | 適応型出題 | Elo方式で問題難易度とユーザー能力を相互更新。回答データ蓄積後 |
| S-08 | PWA／オフライン | Service Workerで問題データをキャッシュ |
| S-09 | 広告表示 | 配置制約は `ads.md` に従う |
| S-10 | 広告非表示オプション | 少額サブスクまたは投げ銭 |

## COULD（将来の拡張候補）

| ID | 機能 | 内容 |
| --- | --- | --- |
| C-01 | 画像問題 | 毛色・馬体・競馬場の識別。権利処理済み素材に限る |
| C-02 | 週間ランキング | 非同期の順位表 |
| C-03 | 効果音 | 正解／不正解の短い音。デフォルトOFF |
| C-04 | 検定モード | ジャンル横断50問で「級」を判定 |
| C-05 | 学習カレンダー | 解答量のヒートマップ表示 |

## 明示的な禁止事項

- 回答ボタン、選択肢、「次の問題へ」ボタンの近傍に広告を配置してはならない
- 回答直後に全画面広告（インタースティシャル）を挿入してはならない
- 音声・BGMを自動再生してはならない
- 課金しないと基本のクイズが遊べない設計にしてはならない
