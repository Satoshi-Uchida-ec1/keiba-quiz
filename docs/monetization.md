# 収益モデル（投げ銭）

## 方針：広告は載せない。収益は投げ銭のみ

広告は一切掲載しない。収益手段は投げ銭（任意の応援）に限定する。

広告を採用しない理由は以下の通り。

- 既存クイズアプリのユーザー不満で最頻出かつ最大なのが広告。本アプリの差別化軸（UXと解説の質）と正面から衝突する
- 個人サイトの広告収益は月数百〜数千円規模の見込みで、UXの犠牲に見合わない
- AdSenseは誤クリック誘発の禁止が厳しく、選択肢ボタンが並ぶクイズUIとは相性が悪い
- ホスティングの無料プラン（Vercel Hobby）は、広告掲載を商用利用として明示的に禁止している

## フェーズ別の扱い

| フェーズ | 収益施策 |
| --- | --- |
| MVP | なし。UXと問題品質に集中 |
| フェーズ2 | 投げ銭リンクを導入。**公開前にホスティング規約を確認する**（後述） |
| フェーズ3以降 | 反応を見て投げ銭サービスや導線を見直す |

## 実装方針

### 外部サービスへの通常リンクで実装する

決済処理を自前で持たない。投げ銭は外部サービス（OFUSE、Ko-fi、Buy Me a Coffee など。選定は未決）に任せ、
アプリ側はそのページへのリンクを置くだけにする。

**埋め込みウィジェット（外部スクリプト）は使わない。** 理由は2つ。

1. 外部スクリプトを読み込むと、ページを開いただけで閲覧者の情報がその事業者に送られる。
   これは電気通信事業法の外部送信規律の対象になり、プライバシーポリシーでの公表が必要になる。
   通常のリンクなら、ユーザーがクリックするまで何も送られない
2. 表示速度が落ちる

### 配置

| 許可する場所 | 形式 |
| --- | --- |
| このサイトについて（P-12） | 説明文つきのリンク |
| サイトフッター | 小さなテキストリンク |
| 解説記事ページ（P-10）の末尾 | 控えめなテキストリンク |
| セッション結果画面（P-06）の最下部 | 控えめなテキストリンク。「もう1セット」等の操作ボタンより下 |

| 禁止する場所・形式 | 理由 |
| --- | --- |
| 出題画面（P-04 / P-05） | 回答への集中を妨げる |
| モーダル、ポップアップ、全画面表示 | 押し付けになる。既存アプリの広告と同じ不満を生む |
| 回答や画面遷移のたびの表示 | 同上 |
| 「応援すると〇〇できる」等の見返り | 下記参照 |

### 投げ銭の有無で機能差をつけない

全機能を無料で提供し、投げ銭は純粋な応援とする。

見返り（限定問題、特典機能など）を付けると、取引の性質が「応援」から「サービスの販売」に近づき、
追加の法的対応（販売者としての表示義務など）が必要になりうる。MVP〜フェーズ2ではそこに踏み込まない。

### 文言

押し付けない。例：

> このクイズを気に入ってもらえたら、開発を応援していただけると励みになります。

「〇〇円で運営が続けられます」のような罪悪感に訴える書き方は避ける。

## 未決：ホスティング規約との関係

Vercel の Hobby（無料）プランは非商用の個人利用に限られ、広告掲載は商用利用の例として明記されている。

**投げ銭の扱いは、Vercel のドキュメントの版によって記載が食い違っている**（商用利用に含むとする版と、含まないとする版がある）。

したがって投げ銭リンクを公開する前に、次のいずれかを行う。

1. その時点の Vercel の最新規約を確認する。判断がつかなければ Vercel サポートに問い合わせる
2. 商用扱いとなる場合は、Vercel Pro（月額20ドル〜）に上げるか、無料枠で商用利用を認めるホスティング（Cloudflare Pages など）へ移行する

投げ銭の見込み額を考えると、Pro 化より移行のほうが現実的な可能性が高い。
Next.js の静的出力を中心にしておけば移行は比較的容易なので、実装時もサーバー機能への依存を増やしすぎないこと。

## 税務

投げ銭の収入は課税対象になりうる。所得区分や申告の要否は金額や本人の状況によって変わるため、
まとまった額になりそうな段階で税理士または税務署に確認する。

## 参考：広告を再検討する場合の制約

将来方針を変えて広告を検討する場合は、以下が前提条件になる（過去の調査結果の記録）。

- ホスティングは商用利用可のプランであること
- 出題画面、および選択肢・「次の問題へ」ボタンから1画面スクロール以内には置かない（誤クリック誘発はアカウント停止事由で復帰困難）
- 回答直後の全画面広告は使わない
- AdSense 審査は「コンテンツ不足」で落ちやすい。解説記事の蓄積が前提
- 馬券の予想・買い方指南に踏み込むと広告ポリシー上の扱いが難しくなる
