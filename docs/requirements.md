## プロダクト概要

### 一行で言うと

競馬と馬に関する知識を、解説を読みながら遊んで身につけるWebクイズアプリ。

### コンセプト：解説で勝つ

既存クイズアプリの最大の不満は「解説がない／薄い」こと。ここにリソースを集中する。
1問ごとに「なぜその答えなのか」と「関連する一歩踏み込んだ知識」を必ず添える。

この方針は3つの効果を同時に生む。

1. **ユーザー価値** — 解いて終わりではなく知識が残る
2. **コンテンツ資産化** — 解説がそのまま読み物になり、検索からの流入の入口になる
3. **リピート理由** — わからなかった問題に戻ってくる動機ができる

### 設計原則

- **速く始められる** — ログイン不要、トップから2タップで1問目
- **UXを収益より優先する** — 広告は載せない。投げ銭は控えめなリンクに留める
- **強制しない** — ストリークには必ず逃げ道をつける。通知は最小限
- **間違いを歓迎する** — 不正解は減点ではなく学習機会。復習に自動で回る
- **正確さに責任を持つ** — 全問に出典を持ち、誤答通報を受け付ける

## ターゲット

初心者からコアファンまで幅広く。ただし単一難易度で全員を満足させるのは不可能なので、入口で二層に分ける。

| 層 | 想定像 | 提供するもの |
| --- | --- | --- |
| 初心者トラック | 競馬を見始めて1〜2年以内 | 「簡単」中心の出題、用語解説、成功体験 |
| コアトラック | 観戦歴が長く血統や記録に詳しい | 「難しい」中心の出題、記録・血統の深い問題 |

初回訪問時に習熟度を1問だけ聞き、初期難易度を決める。スキップ可能、いつでも変更可能。

## スコープ外（やらないこと）

| やらないこと | 理由 |
| --- | --- |
| ユーザー投稿問題（UGC） | 品質のばらつき、著作権侵害の持ち込み、モデレーション工数が許容量を超える |
| リアルタイム対戦 | 技術難度が跳ね上がる。デイリーチャレンジと結果シェアで代替 |
| 外部IP（ウマ娘等）の活用 | 権利リスクをゼロにする。史実特化のほうが差別化になる |
| 多言語対応 | 日本語のみ。文言は外部ファイル化して将来の選択肢だけ残す |
| 広告掲載 | UXの最大の阻害要因で、収益期待値も低い。投げ銭で代替（`monetization.md`） |
| 馬券の予想・買い方指南 | 賭けの推奨に近づく。知識クイズに徹する |
| ネイティブアプリ | Web（PWA）で完結させる |

## 前提としている調査結論

- 既存クイズアプリのユーザー不満で最頻出かつ最大なのは広告の頻度・タイミング・位置
- 次点が「解説がない／薄い」「同じ問題ばかり出る」「誤答が放置される」
- ゲーミフィケーションは継続率に効くが、逃げ道がないと義務感・燃え尽きを招く
- 教室・実課題に近い文脈では即時フィードバックが有効
- JRA・netkeiba・JBIS のデータは規約上、私的利用を超える転載が不可。ただし事実そのものは著作権保護の対象外
